>
> **v3에서 달라진 것**: 앱 이름이 *띵동(听懂 / Tingdong)*으로 정해졌고, 화면이 둘

---

## 1. 목적

중국어로 강의·설교를 준비하는 사람이 **중국어 원고를 붙여넣고**, 원어민 음성을 문장 단위로
따라 읽으며 **발음 연습과 끊김 없는 플로잉 연습**을 한다.

**입력은 순수 중국어라고 가정한다.** 한국어·영어·병음을 걸러내는 일은 사용자가 앱 밖에서
(원고를 정리해서) 해결한다. 앱은 읽어주는 일에만 집중한다.

## 2. 타깃

중국어로 강의/설교를 준비하는 비원어민 발표자. 발표 며칠 전, 노트북 앞에서 30~60분 반복 낭독.

## 3. 성공 기준

1. 원고를 붙여넣고 **3초 안에** 첫 문장이 들린다.
2. 손이 화살표 키에서 떠나지 않고 원고 전체를 훑는다.
3. 30분 연습 동안 설정을 다시 건드릴 일이 없다.

## 4. 기능

### F1. 원고 입력
큰 텍스트 영역에 중국어를 붙여넣고 "시작". 화면 상단 "원고 수정"으로 언제든 되돌아가 고친다.

> **이 텍스트 영역이 곧 편집기다.** 문장을 지우거나 고치고 싶으면 여기서 한다.
> 프롬프터 안에 별도 편집 UI를 만들지 않는다(이전 판의 F12 제거).

**수용 기준**
- [ ] 붙여넣고 "시작"을 누르면 프롬프터 화면으로 전환된다.
- [ ] `.txt` 파일 드래그&드롭도 된다.
- [ ] "원고 수정"으로 돌아가면 이전 내용이 그대로 있고, 고쳐서 다시 시작하면 반영된다.
- [ ] 3,000자를 붙여넣어도 1초 안에 문장 목록이 만들어진다.

### F2. 문장 분할
붙여넣은 중국어를 낭독 단위로 자른다.

- 분할 기준: `。` `！` `？` `!` `?` `；` `;` `…` `……` 직후, 그리고 **줄바꿈**.
- 닫는 따옴표·괄호(`”` `’` `」` `』` `）` `)`)는 **앞 문장에 붙인다.**
- 쉼표(`，` `、`)로는 분할하지 않는다.
- 옵션 "긴 문장 쪼개기": 설정값(기본 45자)을 넘으면 `，`에서 보조 분할. **기본 off.**
- 빈 줄은 버린다.

**수용 기준**
- [ ] `他说：“我来了。”然后走了。` 가 2문장이 되고 첫 문장 끝에 `”` 가 붙어 있다.
- [ ] 마침표 없이 줄바꿈만 있는 원고도 줄 단위로 문장이 된다.
- [ ] "긴 문장 쪼개기"를 켜면 60자 문장이 쉼표에서 갈린다.

### F3. 프롬프터 뷰
현재 문장을 크게, 앞뒤를 흐리게. **현재 문장의 화면 위치는 고정.**

**수용 기준**
- [ ] 현재 문장이 화면 세로 45% 지점에 크게 표시된다.
- [ ] 이전 1~2문장이 위, 다음 2~3문장이 아래에 흐리게 보인다.
- [ ] 넘기면 텍스트가 **위로 부드럽게 밀려 올라가고**(250ms) 현재 문장은 같은 높이에 머문다.
- [ ] 앞뒤 문장 개수와 글자 크기를 설정에서 바꾼다.
- [ ] 전체화면 모드와 진행률(24 / 118)이 있다.

### F4. 문장 낭독
**수용 기준**
- [ ] 문장으로 이동하면 자동으로 읽는다.
- [ ] 문장 전환 후 소리 시작까지 0.5초 이내다(다음 문장 미리 받아두기).
- [ ] 다른 문장으로 이동하면 이전 소리는 즉시 끊긴다.
- [ ] 재생 중인 문장에 시각 표시가 있다.
- [ ] 자동 진행 옵션: 켜면 문장이 끝나고 설정한 간격(기본 0.8초) 뒤 다음으로 넘어간다.

### F5. 키보드 조작

| 키 | 동작 |
|---|---|
| `↓` `→` | 다음 문장 + 낭독 |
| `↑` `←` | 이전 문장 + 낭독 |
| `Enter` | 현재 문장 다시 낭독 |
| `Space` | 재생 / 정지 |
| `Esc` | 정지 |
| `Shift+↓/↑` | 이동만, 낭독 안 함 |
| `+` `-` | 글자 크기 |
| `[` `]` | 속도 |

**수용 기준**
- [ ] 표대로 동작하고, 화살표가 페이지 스크롤을 일으키지 않는다.
- [ ] 처음/끝에서 더 눌러도 오류 없이 머문다.
- [ ] **연타해도 음성이 겹치지 않는다.**

### F6. 목소리 (성별 × 톤)
**성별** 남/여 · **톤** 강의 / 설교 / 뉴스 / 대화. 매핑은 `03-architecture.md`.

**수용 기준**
- [ ] 고르면 즉시 현재 문장이 그 목소리로 다시 들린다.
- [ ] 톤을 바꾸면 **귀로 구분되는 차이**가 난다(강의=또렷·균일, 설교=느리고 호흡이 길다).
- [ ] 선택이 다음 실행에도 유지된다.
- [ ] 어떤 조합이 어떤 실제 음성인지 화면에 표시된다(예: 남성·설교 → 云健).

### F7. 속도
**수용 기준**
- [ ] 0.5x ~ 1.5x, 5% 단위. 슬라이더와 `[` `]` 양쪽으로 조절.
- [ ] 바꾸면 다음 낭독부터 즉시 적용되고, 현재 배속이 숫자로 보인다.
- [ ] (선택) 피치 ±10%.

### F8. 병음 표시 (옵션)
**수용 기준**
- [ ] 토글을 켜면 현재 문장 **바로 아래**에 병음이 한 줄로 뜬다.
- [ ] 다음자가 문맥에 맞다(`银行 yínháng`, `行走 xíngzǒu`).
- [ ] 성조 부호 표기 기본, 숫자 표기(`ni3 hao3`) 옵션.
- [ ] 앞뒤 문장 병음은 따로 켠다(기본: 현재 문장만).
- [ ] 켜고 꺼도 현재 문장의 화면 위치가 튀지 않는다.

### F9. 설정·세션 유지
**수용 기준**
- [ ] 목소리·속도·병음·글자 크기·앞뒤 개수가 앱을 껐다 켜도 남는다.
- [ ] 다시 열면 **마지막 원고와 읽던 문장 위치**가 복원된다.
- [ ] 최근 원고 5개를 제목으로 저장하고 불러온다.

### F10. 프라이버시·폴백 (★)
온라인 TTS를 쓴다 = **원고 문장이 외부 서버로 전송된다.**

**수용 기준**
- [ ] 첫 실행 시 "문장이 음성 합성을 위해 마이크로소프트 서버로 전송됩니다"를 1회 고지하고 동의받는다.
- [ ] **"오프라인 전용 모드"** 스위치: 켜면 기기 내장 음성만 쓰고 네트워크 요청을 일절 안 한다.
- [ ] 네트워크 실패 시 자동으로 내장 음성 폴백 + 상단 배너 고지.
- [ ] 원고와 오디오 캐시는 기기 안에만 저장된다.

## F11. 영어권 배포판 (v3 · 2026-09-02)

앱을 한국어를 모르는 사람에게 줄 수 있게 만든다.

**핵심 결정: 화면 언어와 번역 타깃은 한 설정이다.** 화면은 영어인데 뜻은 한국어로 나오면
앱이 두 쪽으로 갈라진다. `언어 = 한국어`면 중→한, `Language = English`면 중→영이다.
따로 고르게 하지 않는다.

이유: 이 앱의 사용자는 "중국어를 배우는 사람"이고, 그가 아는 언어는 하나다. 화면 언어를
고르는 행위가 곧 "내가 아는 언어는 이것"이라는 선언이다.

### F11-1. 언어 전환
**수용 기준**
- [ ] 두 화면(번역기·읽기 연습) 어디서나 닿는 곳에 언어 선택이 있다.
- [ ] 바꾸면 **새로고침 없이** 화면 문구가 즉시 바뀐다.
- [ ] 선택이 앱을 껐다 켜도 유지된다(`localStorage`).
- [ ] 처음 켠 사람은 기기 언어를 따라간다 — 한국어 기기면 한국어, 그 밖에는 영어.

### F11-2. 번역 타깃 전환
**수용 기준**
- [ ] `English`에서 중국어를 넣으면 **영어 번역**이 나온다(문장·단어 모두).
- [ ] 언어를 바꾸면 이미 화면에 있던 번역이 **새 언어로 다시 번역된다** — 옛 언어 결과가 남지 않는다.
- [ ] 읽기 연습의 단어 카드 뜻도 같은 언어로 나온다.
- [ ] 중국어가 아닌 글을 넣었을 때의 중국어 변환(역방향)은 두 언어 모두에서 그대로 동작한다.
- [ ] **번역이 도중일 때 언어를 바꿔도** 화면에 두 언어가 섞이지 않는다. 옛 언어로 진행 중이던
      요청의 응답은 도착하더라도 버린다 — 이미 있는 회차 카운터(`runId`)를 언어 전환에도 건다.
- [ ] 언어를 바꾼 뒤 단어 하나에 마우스를 올렸을 때, 이전 언어로 받아둔 단어 뜻이 그대로
      보이지 않는다(캐시는 언어별로 나뉜다).

### F11-3. 교차 하이라이트 (언어별)
왼쪽 한자에 마우스를 올리면 오른쪽 번역에서 대응하는 자리가 강조된다. 이 매칭은
언어마다 규칙이 다르다.

**수용 기준**
- [ ] 한국어: 지금 규칙 유지(2글자 이상, 부분 문자열 — `기적`이 `기적도`에 걸린다).
- [ ] 영어: 대소문자·구두점을 무시하고 낱말 단위로 맞춘다(`Miracle,` ↔ `miracle`).
- [ ] 영어에서 `a` `of` `the` 같은 기능어가 문장 절반을 물들이지 않는다.
- [ ] 두 규칙 모두 순수 함수로 분리해 테스트가 있다.

### F11-4. 남는 한국어 0
**수용 기준**
- [ ] `English`로 두고 두 화면을 끝까지 조작했을 때 **화면에 한글이 하나도 없다** — 버튼·
      메뉴·툴팁·플레이스홀더·상태 배지·오류 문구 전부.
- [ ] 앱 창 제목·트레이 메뉴 등 Electron 껍데기도 영어다.
- [ ] ⌘⇧F 팝업도 영어다.
- [ ] 소스 주석은 한국어 그대로 둔다 — 읽는 사람이 다르다.
- [ ] 육안 확인에만 기대지 않는다: 문자열표의 `en` 쪽 전체에 한글(`[가-힣]`)이 0건임을
      기계로 확인한다. 화면에 뜨는 문구는 모두 이 표에서 나오므로, 표가 깨끗하면
      남는 것은 표 밖에 하드코딩된 문구뿐이고 그건 코드 검색으로 잡는다.

### F11-5. 회귀 없음
**수용 기준**
- [ ] `한국어`로 두면 v2까지의 문구·동작이 그대로다.
- [ ] 기존 저장 설정(`prompter.settings` 등)이 언어 도입 때문에 초기화되지 않는다.

## 5. 범위

F1 ~ F11. 맥 데스크톱(Electron). 화면 둘: 번역기 · 읽기 연습.

## 6. 비범위

- **원고 정제(한국어·영어·병음 걸러내기)** — 사용자가 앱 밖에서 해결. 필요해지면 `cef9684`에서 되살린다
- `.docx` / `.pdf` 파싱
- 프롬프터 안 인라인 편집·삭제·undo — 입력 화면의 텍스트 영역이 대신한다
- 녹음·발음 채점(마이크 미사용), 한국어 번역 표시, 단어별 노래방 싱크
- 클라우드 동기화, 계정, 웹/모바일
- **세 번째 언어**(일본어·중국어 UI 등) — 두 언어로 구조만 잡고, 늘리는 건 그때 가서
- **화면 언어와 번역 타깃을 따로 고르기** — F11의 핵심 결정을 뒤집는 일. 요구가 실제로 생기면 그때
- 번역문의 영어 품질 손보기 — 무료 구글 엔진이 주는 그대로 쓴다

## 7. 리스크

| 리스크 | 대응 |
|---|---|
| Edge TTS는 비공식 엔드포인트라 막힐 수 있다 | 내장 음성 폴백을 **Phase 2에서 같이** 만든다. 엔진 인터페이스를 분리해 Azure 키로 갈아탈 수 있게 |
| 톤 차이가 귀로 안 들려서 기능이 무의미해진다 | Phase 3 시작 전 실제 샘플을 듣고 매핑 확정. 차이가 없으면 톤을 rate/pitch 프리셋으로 축소 |

| 붙여넣은 원고에 한국어가 섞여 들어와 엉뚱하게 읽힌다 | **의도된 제약.** 사용자 책임. 반복되면 파서를 되살린다 |
| 문구를 옮기다 한 곳을 빠뜨려 영어 화면에 한글이 남는다 | 문자열을 한 파일(`i18n.ts`)에 모으고, **영어를 원본**으로 두어 한쪽에만 있는 키는 타입 검사에서 걸리게 한다. 게이트에서 화면 전수 확인 |
| 영어 교차 하이라이트가 기능어에 다 걸려 문장이 통째로 물든다 | F11-3. 낱말 단위 매칭 + 최소 길이 + 불용어 제외. 순수 함수로 떼어 테스트 |
| 언어를 바꿨는데 옛 언어 번역이 화면에 남는다 | 언어를 번역 재실행의 입력으로 걸어둔다(F11-2) |
| 읽기 연습의 `readMode: 'chinese-english'`가 영어판에서 뜻이 달라진다 — 영어가 번역문의 언어이면서 동시에 "원고에서 걸러낼 대상"이다 | 원고 필터는 **원고의 언어** 이야기이고 화면 언어와 무관하다. 라벨을 그렇게 읽히게 쓴다 |

# F12 — 짧은 성경 단락 학습 (2026-10-22, 첫 구현)

이 증분은 앞의 원고 전용 목적·화면 둘·성경 관련 비범위에 우선한다. F1~F11은 유지한다.
사용자 결정: 하루 한 장 대신 이야기/소주제별로 공부한다. 소주제가 없으면 최대 5절씩 나누며,

# F14 — 안정적인 고품질 중국어 음성 (2026-10-22)

## 문제와 목표

Edge TTS가 HTTP 403으로 거부되면 macOS 기기 음성으로 넘어가지만, 그 발음 품질은 중국어 학습에
부족하다는 사용자 피드백이 있습니다. 기기 음성을 학습용 기본 대안으로 삼지 않고, 공식 인증된
고품질 온라인 중국어 TTS를 쓸 수 있게 합니다. Google 번역기 음성 자체를 추출하는 비공식 경로는
안정성과 서비스 약관 문제가 있어 제품 엔진으로 사용하지 않습니다.

## 범위와 결정

- 공식 후보는 Google Cloud Text-to-Speech의 Mandarin `cmn-CN`입니다. 먼저 비용이 낮은 WaveNet과
  Standard, 그 다음 Chirp 3 HD의 실제 샘플을 비교합니다. Google 번역기 음성과 동일하다고 주장하지 않습니다.
- Cloud TTS `text.synthesize`는 OAuth `cloud-platform` 범위를 요구합니다. 데스크톱 앱에 API 비밀키나
  서비스 계정 키를 넣지 않습니다. 사용자 본인의 Google OAuth 동의로 짧은 수명의 access token을 받고,
  refresh token은 macOS Keychain 연동 Electron `safeStorage`로 암호화해 저장합니다.
- 첫 범위는 현재 앱 소유자의 개인 Mac에서 사용하는 개발/배포 앱입니다. 다른 사용자에게 공개 배포하는
  경우 OAuth 동의 화면 검증, 사용자별 Google Cloud 결제 프로젝트, 계정/쿼터 구조를 별도 검토합니다.
- 기존 문장 음성 캐시를 영속 캐시로 확장합니다. 키에 본문·음성·속도·음높이·엔진 버전을 포함하고,
  반복 재생은 캐시 음원을 사용합니다. 캐시 삭제 수단과 저장 위치/용량 제한을 제공합니다.
- 연결 설정에서 Desktop OAuth client ID와 TTS API가 켜진 quota/billing project ID를 받습니다.
  사용자가 프로젝트에 TTS API와 결제를 직접 설정하고 `serviceusage.services.use` 권한을 보유해야 합니다.
  API 호출에는 `x-goog-user-project`를 지정합니다. Google 로그인 완료와 음성 준비 완료를 별개 상태로 표시합니다.
- 월 사용량은 UTC 기준으로 이 앱이 외부 전송을 시작한 합성 요청의 입력 글자 수를 원자적으로 예약해 집계합니다.
  중복 동시 요청은 합치고, 샘플/재시도도 사용량에 포함하며, 전송된 뒤 타임아웃·취소·서버 오류가 난 요청은
  과금 여부를 알 수 없으므로 상한 계산에서 차감하지 않습니다. 프리페치는 끕니다. 캐시 재생은 세지 않습니다.
  기본 월 상한 800,000자는 로컬 설치본의 새 요청만 제한하며 Cloud 프로젝트의 총 사용량/비용 상한을 보장하지 않습니다.
  집계 파일이 손상되거나 안전 저장이 불가능하면 새 합성을 막고 재인증/원장 재설정 안내를 표시합니다.
- 로그인 전/토큰 오류/네트워크/쿼터 초과 때 기기 음성으로 자동 전환하지 않습니다. 재시도, 다른 온라인
  음성, 명시적 기기 음성 선택을 제공하고 실패를 표시합니다.
- Edge TTS는 선택적 기존 엔진으로 유지하되, 반복 403 요청을 하지 않습니다. 온라인 기본 설정은
  계정 연결 전까지 기존 사용자 선택을 보존하고, 신규 설치는 안전하게 정합니다.
- 단락의 각 문장을 클릭해 반복하는 현재 동작을 유지합니다. 남녀 음성, 음높이, 배속을 각각 지원하는
  음성 프로파일을 제공하고 실제 API가 지원하지 않는 스타일 효과를 된다고 표시하지 않습니다.

# F16 — 기존 성경 번역문과 문장별 자동 진행 (2026-10-24)

사용자 요청으로 성경 공부 화면의 절별 한국어·영어 뜻을 앱이 새로 풀어쓴 문장이 아니라
확인 가능한 기존 번역문으로 교체하고, 문장 반복 조작을 실제 학습 흐름에 맞게 다듬습니다.

## 범위와 결정

- 중국어 본문은 기존 eBible `cmn-cu89s`를 유지합니다.
- 한국어는 eBible의 **한국어 성경 1910**(Public Domain), 영어는 eBible의 **World English Bible Classic**
  (Public Domain) 마가복음 1장 본문을 절 번호에 맞춰 로컬 번들로 보관합니다. 실행 중 번역 API를 호출하지 않습니다.
- 번역문은 임의로 현대화하거나 다시 번역하지 않습니다. 따옴표·공백 같은 표시 형식만 앱 표시용으로 정리할 수 있습니다.
- 단어 뜻·문법 설명·연습 예문은 기존 학습용 작성 자료이며, 성경 번역문과 구분해 표시합니다.
- 반복 횟수는 `1회 / 3회 / 5회 / 계속 반복`입니다. 유한 횟수로 문장을 반복한 뒤 현재 단락의 다음 문장으로 자동 이동합니다.
  마지막 문장까지 끝나면 멈춥니다. `계속 반복`은 기존처럼 해당 문장을 계속 반복하며 자동 이동하지 않습니다.

## 수용 기준

| ID | WHEN / SHALL |
|---|---|
| F16-1 | 본문 뜻의 한국어·영어 45절이 각각 지정된 기존 번역본의 절 내용과 일치하고, 화면에 번역본 이름·출처 링크를 안내합니다. |
| F16-2 | 앱 실행 중 한국어·영어 뜻을 만들기 위한 번역 네트워크 요청이 없고, 소스 데이터에 45절의 두 언어가 모두 존재합니다. |
| F16-3 | 단어·문법의 앱 작성 학습 자료와 기존 성경 번역문이 화면에서 혼동되지 않으며, 영어 UI에서도 두 언어 뜻이 함께 보입니다. |
| F16-4 | 반복 선택지에 `1회`가 표시되고 저장·재로드 후에도 유효합니다. 유효하지 않은 반복값은 기본값으로 복구합니다. |
| F16-5 | 유한 반복이 끝나면 다음 문장이 같은 반복 설정으로 시작하고, 단락 마지막 문장 뒤에는 멈춥니다. 정지·다른 문장 선택·단락/탭 전환은 자동 대기를 취소합니다. |

# F17 — 개인용 새한글성경 로컬 불러오기 (2026-10-24)

기본 번역문은 F16과 같이 유지합니다. 사용자가 별도로 권리를 확인한 새한글성경 본문을 개인 Mac에서만 선택해 사용할 수 있게 하며, 본문은 저장소·배포 번들·네트워크에 포함하지 않습니다. 새 사용자는 파일이 없으면 한국어 성경 1910을 계속 사용합니다.

| ID | WHEN / SHALL |
|---|---|
| F17-1 | 사용자는 마가복음 1장 새한글성경 JSON을 직접 선택할 수 있습니다. 앱은 version 1, 판본 ID, Mark 1, 1~45절 전체와 비어 있지 않은 본문을 검증합니다. |
| F17-2 | 앱은 검증된 파일을 Mac의 앱 전용 userData/private-bible에만 저장하고, 저장소·패키지에 넣거나 업로드하지 않습니다. |

## F18 — 로컬 판본 선택과 BDB 자동 변환

한국어와 영어 각각 여러 로컬 판본을 등록하고 드롭다운에서 선택합니다. 사용자는 원본 `.bdb` SQLite 파일 또는 앱 JSON을 직접 불러오며, 앱은 마가복음 1장만 변환해 개인 userData에 저장합니다. 선택된 파일이 없으면 해당 언어의 기본 판본으로 실행하고 누락 사실을 안내합니다. 낭독 간격에는 `연속`을 추가해 대기 없이 다음 문장으로 진행합니다.

## F19 — 자동 진행 위치 표시와 성경 범위 확장 준비

자동 낭독으로 다음 문장으로 이동하면 현재 문장이 화면 가운데 근처에 보이도록 스크롤합니다. 현재 저장소의 실제 기본 본문 범위는 마가복음 1장이며, 추가 장은 원문·번역문·학습 자료가 함께 준비된 경우에만 장 단위로 추가합니다.

## F21 — 낭독 준비 상태 회복

연속으로 다음 절을 선택하거나 음성 요청이 늦어져도 `음성 준비 중` 상태에 영원히 머물지 않아야 합니다. Edge 합성 응답은 타임아웃을 두고, 기기 음성은 `speak()` 호출을 즉시 시작으로 반영하며 실패 이벤트 발생 시 오류로 회복합니다. 이전 문장의 늦은 응답은 현재 문장을 덮어쓰지 않습니다.

현재 문장 위치를 저장하며 화면을 다시 그릴 때도 같은 책·장·학습 단위의 낭독은 유지되어야 합니다. 실제 단락이나 설정이 바뀌었을 때만 낭독을 중지합니다.
