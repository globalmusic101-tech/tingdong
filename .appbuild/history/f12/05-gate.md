## 기획 검토 판정

**기획 PASS — F12 구현 착수 가능. 구현 완료 판정은 PENDING입니다.**

검토 대상은 01-prd의 F12-1~9, 02-screens의 S4, 03-architecture의 F12, 04-tasks의 B1~B4입니다.
현행 SentencePlayer와 webSpeech도 읽어 공용 음성 모듈의 오류 처리 변경 범위를 확인했습니다.
이번 검토에서는 소스 코드를 변경하거나 실행하지 않았습니다.

- 이야기/소주제 우선, 소주제 없는 구간 최대 5절, 다음 단락 자율 진행이 일치합니다.

- 단락/문장 ID와 절 보존, 부분 heading, 잘못된 데이터, 재생 취소, 저장 검증과 오류 노출이 명시되었습니다.
- 고아 요구 0, 고아 작업 0입니다. B1→B2/B3→B4의 의존 순서로 구현 가능합니다.
- 기획상 CRITICAL/HIGH/MED 결함 0입니다. 구현 증거가 없으므로 현재 기능 통과 항목은 0건입니다.

주의 사항: 현행 기기 음성은 `utterance.onerror = onEnd`로 실패를 완료 처리합니다.
F12-7에서 이를 바로잡고 기존 읽기 연습까지 회귀 확인해야 합니다. 새 화면은 기존 무음 설정을
물려받아 소리 없이 반복 횟수를 올려서는 안 됩니다. F10의 전송 고지 원칙을 유지하여
온라인 음성 사용 전에 전송 안내와 사용자 선택을 확인해야 합니다.

## 완료 판정 규칙

모든 행이 실제 증거로 PASS이고 미해결 CRITICAL/HIGH가 없을 때만 F12 구현 완료 PASS입니다.
도구 또는 실기 검증을 못 하면 해당 행을 미확인/부분으로 남기고 조건부 상태로 보고합니다.

사람이 직접 듣는 발음·성경 고유명사 병음 품질 검토는 자동 오디오 이벤트 확인과 별도입니다.
듣지 않았다면 들었다고 보고하지 않습니다. 단어/문법 해설, 암기/SRS, 전체 성경, 실제 설교 학습은
이번 완료 범위에 포함하지 않습니다.

**현재: 기획 PASS / 첫 구현 및 패키징 완료 · 전체 검증은 부분 상태.**

세부 실행 증거와 한계: `../docs/F12-verification.md`. 기획 감독관의 PASS를 구현 PASS로 재사용하지 않습니다.
