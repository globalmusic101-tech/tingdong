# 02-Screens — 띵동 (Tingdong)

> 2026-09-02 · 상위: [[appbuild-screen-spec]] · 앞: `01-prd.md` → 다음: `04-tasks.md`
>
> 이 문서는 v3에서 처음 쓴다. 그전까지 화면 명세 없이 만들어졌고, 지금 있는 화면을
> **있는 그대로 적은 뒤** F11(영어권 배포판)이 각 화면에 무엇을 요구하는지 붙인다.
> 그래서 "새로 만들 화면"은 없다 — 바뀌는 건 문구와 언어 하나다.

---

## 1. 화면 흐름

```
                    ┌──────────────────────────┐
        앱 실행 ───→ │  AppShell (탭 + 언어)     │
                    └──────────┬───────────────┘
                               │  탭으로 전환 (app.mode에 저장)
                 ┌─────────────┴─────────────┐
                 ▼                           ▼
          S1 번역기                    S2 읽기 연습
                                             │
                                  ┌──────────┴──────────┐
                                  ▼                     ▼
                            S2a 원고 입력  ──시작→  S2b 진행
                                  ◀──원고 수정──┘

        S3 단어 팝업 (⌘⇧F) — 별도 창. 어느 화면에서든 전역 단축키로.
```

- 진입점은 하나(앱 실행). 마지막으로 보던 탭이 복원된다(`app.mode`).
- S1 ↔ S2 전환에 확인 절차 없음 — 양쪽 다 입력이 `localStorage`에 남는다.
- S3는 렌더러 트리 밖의 독립 창이다. 컨텍스트가 닿지 않아 언어를 **직접 읽는다**.

### 언어 컨트롤의 자리

`AppShell`의 탭 줄 **오른쪽 끝**. 두 화면 어디서나 같은 자리에 있고(F11-1), 화면
안쪽 설정에 숨기지 않는다 — 영어권 사용자가 처음 앱을 열었을 때 한글 화면이면
가장 먼저 찾아야 하는 것이 이것이다.

## 2. 화면별 상세

### S1 — 번역기 (`App.tsx`)

붙여넣은 중국어를 문장 단위로 번역하고, 한자에 마우스를 올리면 병음·발음·뜻을 준다.

**레이아웃**

```
┌─ header ────────────────────────────────────────────────┐
│ 띵동 (听懂)   [설정] [문장형|단어형] [호버|항상 병음]      │
│               [직역|현지화] [단어 자동 번역: 켬]           │
├─ (설정 창 — 접힘) ───────────────────────────────────────┤
├─ 왼쪽 pane ──────────────┬─ 오른쪽 pane ─────────────────┤
│ 중국어(간체) - 감지됨    │ 한국어 / English   [상태 배지] │
│                          │                               │
│ 편집 중: textarea        │ 문장별 번역                   │
│ 보기 중: 단어 블록들      │  · 문장 hover → 밑줄          │
│   (병음 + 한자)          │  · 단어 hover → 대응 낱말 강조 │
│                          │                               │
│ 0 / 5000                 │                               │
└──────────────────────────┴───────────────────────────────┘
```

**상태**

| 상태 | 화면 |
|---|---|
| 빈 화면 | 왼쪽 `텍스트 입력` 플레이스홀더, 오른쪽 `번역이 여기에 표시됩니다.` |
| 입력 중 | textarea 유지. 800ms 디바운스 후 번역 시작 |
| 번역 중 | 오른쪽 헤더에 `번역 중...` |
| 정상 | 오른쪽에 문장별 번역 + 상태 배지 `Google 번역 (무료)` |
| **부분 실패** | 실패한 문장 자리에 `⚠️ 번역 실패 [다시 시도]` + 원문. 상단에 몇 문장이 실패했는지 |
| 전체 실패 | 상태 줄에 사유. 번역 영역은 비우고 원고는 남긴다 |
| 중국어 변환 실패 | 한국어/영어를 넣었는데 중→변환이 실패한 경우. 사유를 상태 줄에 |

> 실패를 빈칸으로 삼키지 않는다 — 원고에서 문장이 조용히 빠지는 것이 가장 나쁘다.

**컴포넌트 / 데이터**

| 요소 | 데이터 | F |
|---|---|---|
| 왼쪽 단어 블록 | `WordData{chinese, pinyin, translationLiteral}` | — |
| 오른쪽 문장 | `SentenceData{chinese, translated, failed, retrying}` | — |
| 단어 hover | 병음 툴팁 · Web Speech 발음 · 250ms 후 뜻 조회 | — |
| 교차 하이라이트 | `highlightedWords: string[]` + 언어별 매칭 규칙 | **F11-3** |
| 상태 배지 | `engineStatus` 문자열 | — |

**F11이 요구하는 것**
- 헤더·설정 창·양쪽 pane 머리말·플레이스홀더·상태 배지·실패 문구가 전부 화면 언어를 따른다.
- 오른쪽 pane 머리말은 언어 그 자체다 — `한국어` / `English`.
- 번역 타깃이 화면 언어를 따른다. 언어를 바꾸면 화면에 있던 번역이 다시 만들어진다(F11-2).
- 교차 하이라이트가 언어별 규칙을 쓴다(F11-3).

### S2a — 읽기 연습 · 원고 입력 (`ScriptInput.tsx`)

**레이아웃**

```
┌─────────────────────────────────────────┐
│ 중국어 원고 붙여넣기                      │
│ (설명 한 문단)                            │
│ ┌─────────────────────────────────────┐ │
│ │ textarea — 드래그&드롭 대상           │ │
│ └─────────────────────────────────────┘ │
│ (오류 줄 — 있을 때만)                     │
│ 1,204자 · 38문장 · 건너뛴 줄 3           │
```

**상태**

| 상태 | 화면 |
|---|---|
| 비어 있음 | 중국어 예문 플레이스홀더. `시작` 비활성 |
| 원고 있음 | 글자 수·문장 수·건너뛴 줄 수. `시작` 활성 |
| 드래그 중 | textarea 테두리 강조 |
| 파일 오류 | 빨간 줄 — `.docx` 실패 / 못 읽는 형식 / 바이너리 / 읽기 실패 4종 |
| 되돌아옴 | 읽던 문장이 선택된 채 그 위치로 스크롤 |

**F11이 요구하는 것**: 제목·설명·카운트·읽기 모드 선택지·버튼·**오류 4종**이 화면 언어를
따른다. 오류 문구는 평소 안 보이므로 빠뜨리기 쉽다 — 게이트에서 4종을 각각 확인한다.

## 3. 명시적 비목표 (검증에서 걸린 것들)

- **F10의 "첫 실행 1회 고지·동의"** — `[NON-GOAL for v3]`. 01-prd F10의 수용 기준에는
  있으나 화면이 만들어진 적이 없다. 이번 증분(F11)의 범위가 아니고, 다국어와도 무관하다.
  되살릴 때 여기에 화면을 붙인다.
- **인증·권한** — `[NON-GOAL]`. 로컬 전용 데스크톱 앱이고 계정이 없다. 보는 사람과
  하는 사람이 언제나 같은 한 사람이다.
- **언어 전환의 실패 상태** — `localStorage`가 막혀 저장에 실패해도 화면은 바뀐다.
  그 세션 동안만 유지되고 조용히 넘어간다. 별도 오류 표시를 두지 않는다 — 사용자가
  할 수 있는 일이 없다.

# F12 — 성경 공부 화면 (2026-10-22)
기존 두 탭 옆 성경 공부 탭. 새 사용자는 성경 공부를 기본으로, 기존 사용자는 저장 탭 유지.

S4: 상단에 시범 범위(마가복음 1장), 제목, 짧은 학습 안내. 왼쪽 단락 목록과 분할 방식(이야기별/5절씩), 완료 여부.
중앙에 현재 단락 소주제/절 범위, 본문 문장 버튼(절 번호는 별도), 선택/재생 강조.
도구: 단락 듣기, 정지, 병음, 배속, 반복 횟수, 쉬는 시간, 온라인/기기 음성.
하단: 이전 단락 / 공부 완료 / 완료하고 다음 단락 / 다음 단락. 최종 단락에는 다음 버튼 비활성.
소주제 없는 단락은 중립적 절 범위 제목 + 5절 구분 표시. 긴 소주제도 사용자가 5절씩 모드로 전환 가능.
읽기 완료와 암기 완료를 혼동하지 않는 문구. 완료를 취소할 수 있다.

상태: 정지/준비/재생/반복 대기/오류를 눈으로 구분. 현재 반복 횟수 표시.
오류 시 본문 유지, 재생을 다시 누르라는 안내. 저장 실패는 별도 배너.
작은 창은 목록을 위로 이동. 모든 조작은 button/select/label로 키보드 접근, 활성 단락 aria-current.
출처 설명은 하단 details로 접어둔다. 음성 전송 안내는 엔진 선택 가까이 표시.

# F13 — 본문·단어·문법 영역
S4 본문 제목 바로 아래 눈에 보이는 3개 학습 탭: 본문 / 단어 공부(개수) / 문법 공부(개수).
본문: 중국어 문장 아래 절 전체 한국어·English 뜻을 2열로 배치(좁은 창은 세로).
기존 낭독 조작부에 뜻 표시 체크박스. 풀이 자료 성격을 짧게 안내.
단어: 단락의 단어 카드 목록. 한자/병음/절/중국어 용례, 2열 한국어·영어 뜻. 카드별 뜻 가리기,
뜻 확인 후 기억함/다시 공부. 기억 상태 표시·취소 가능. 암기 시험 점수나 SRS로 표방하지 않음.
문법: 패턴 카드 목록, 실제 본문 인용과 절, 문장 구성, 두 언어 설명, 현대 연습 예문과 뜻.
학습 탭은 aria-pressed 버튼이고 카드 조작은 native button. 전환 시 낭독 정지.
모든 데이터는 현재 단락 범위를 따르고 단락 이동/5절 전환 후 학습 탭을 유지해 바로 공부 가능.

# F14 — 온라인 고품질 음성
읽기 연습과 성경 공부의 음성 선택에 Google Cloud TTS 연결 상태와 음성 선택을 노출합니다.
계정 미연결이면 Google 로그인/연결 해제, 사용 목적·전송 데이터·무료 한도/과금 조건을 먼저 설명합니다.
초기 설정에서 공개 Desktop OAuth client ID와 TTS API 활성화/결제 연결이 된 Cloud quota project ID를 받습니다.
프로젝트 준비 체크리스트(결제·API enable·serviceusage.services.use·사용자 test-user/OAuth 설정)를 보여줍니다.
Google 계정 인증, Cloud project 준비, TTS 음성 요청 성공은 각각 다른 상태로 표시합니다.
음성 목록에는 모델, 중국 본토/대만 중국어, 성별, 듣기 샘플을 표시하고 현재 선택을 눈에 보이게 합니다.
설정의 목소리 인물(성별)·음높이·배속은 선택된 엔진이 실제 지원하는 값만 보여줍니다.

# F16 화면 증분 — 기존 번역문과 자동 진행

성경 본문 뜻 카드는 중국어 절 아래에 한국어와 English를 나란히 표시합니다. 두 문구는 각각
`한국어 성경 1910`과 `World English Bible Classic`에서 가져온 기존 번역문이며, 본문 하단의
출처 안내에서 두 원문 링크를 제공합니다. 단어·문법 카드의 앱 작성 풀이와 연습 예문은
`앱 작성 학습 자료`로 계속 구분합니다.

반복 횟수 선택지는 `1회`, `3회`, `5회`, `계속 반복`입니다. 유한 반복 중에는 현재 문장의
읽기 횟수를 표시하고, 횟수가 끝나면 쉬는 시간 뒤 다음 문장을 자동으로 읽습니다. 단락의
마지막 문장을 끝내면 정지합니다. 계속 반복은 다음 문장으로 넘어가지 않습니다.

## F17 화면 증분 — 개인용 새한글성경

본문 안내 영역에 선택적 로컬 불러오기 패널을 둡니다. 파일이 없을 때는 기본 한국어 성경 1910 사용 상태를 표시하고, 불러오기에 성공하면 새한글성경 이름과 개인용 로컬 상태를 표시합니다. 본문은 저장소·앱 번들에 포함하지 않습니다.

## F18 화면 증분 — 판본 선택과 연속 읽기

본문 안내 영역에 한국어·영어 판본 드롭다운과 각 언어의 BDB/JSON 불러오기 버튼을 표시합니다. 등록된 판본이 없으면 기본 판본 항목만 보이고, 선택 파일이 사라지면 기본 판본으로 바뀌었다는 안내를 표시합니다. 따라 말할 시간의 첫 항목은 `연속`입니다.

## F20 화면 증분 — 66권 책·장 선택

성경 공부 왼쪽에 66권 책 선택과 해당 책의 장 선택을 표시합니다. 장을 바꾸면 현재 단락과 낭독 위치를 새 장의 첫 문장으로 바꾸며 자동 재생하지 않습니다. 마가복음 1장 외 장에서는 본문 읽기·듣기를 제공하고, 준비되지 않은 학습 카드에는 자료 없음 안내를 표시합니다.

## F21 화면 증분 — 낭독 준비 시간 제한

음성 요청이 정해진 시간 안에 시작되지 않으면 준비 상태를 해제하고 폴백 또는 오류를 표시합니다. 다음 문장으로 전환한 뒤 이전 응답이 도착해도 현재 문장의 상태를 바꾸지 않습니다.
## F22 화면 증분 — 성경 낭독 음성과 책 표시

성경 공부 낭독 영역에 남성/여성 및 설교형/뉴스형/대화형 드롭다운을 표시합니다. 왼쪽에서 책을 바꾸면 오른쪽 본문 제목과 단락 목록도 같은 책으로 바뀝니다.

## F23 화면 증분 — 66권 문맥 단락

‘이야기별’ 목록은 문맥 제목을 크게, 책·장·절 범위를 작게 표시합니다. 소제목이 없는 장은 ‘장 전체 문맥’으로 표시하고 5절 단위 학습과 구분합니다. 긴 문맥은 현재 선택한 문장을 중심으로 읽고 자동 스크롤합니다.

## F24 화면 증분 — 로컬 판본 적용 범위

마가복음 1장 전용 로컬 판본은 마가복음 1장에서만 적용합니다. 다른 책·장에서는 해당 본문에 맞는 기본 한국어·영어 뜻을 표시합니다.
