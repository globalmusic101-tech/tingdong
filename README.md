# 윤선생 중국어 공부앱

중국어 학습용 맥 데스크톱 앱 (Electron + React + TypeScript). 두 가지 모드로 쓴다.

## 번역기

중국어 문장을 붙여넣으면 단어 단위로 쪼개 병음과 뜻을 보여준다. `⌘⇧F`로
다른 앱에서 선택한 글자를 팝업으로 번역한다.

## 읽기 연습 (프롬프터)

강의·설교 원고를 문장 단위로 읽어주며 따라 읽게 한다.

- **원고 넣기** — 붙여넣기 또는 워드(.docx) 끌어다 놓기
- **무엇을 읽을지** — 한국어·병음은 건너뛰고, 문장에 섞인 영어는 읽는다
- **낭독** — Edge TTS 중국어 음성(남/여 × 설교·뉴스·대화), 속도·음높이 조절
- **프롬프터** — 현재 문장을 화면 중앙에 고정하고 나머지가 흘러간다. 글자 최대 160px
- **구간 반복** — `A`…`B`로 구간을 잡아 반복, `C`로 해제
- **병음** — 글자마다 성조를 위 또는 아래에 붙인다
- **소리 끄기** — 음성 없이 읽는 속도에 맞춰 저절로 넘어가는 프롬프터
- **위치 싱크** — 원고에서 커서를 둔 자리부터 읽고, 돌아가면 읽던 문장을 보여준다

### 단축키

| 키 | 동작 |
|---|---|
| `Space` | 다음 문장 |
| `↑` `↓` | 이동 (`Shift`와 함께 누르면 소리 없이) |
| `Enter` | 다시 듣기 |
| `Esc` | 정지 |
| `A` `B` `C` | 구간 지정 / 끝 / 해제 |
| `[` `]` | 속도 |
| `+` `-` | 글자 크기 |

## 개발

```bash
npm install
npm run dev        # 브라우저 (기기 내장 음성으로 폴백)
npm run app:dev    # Electron — 온라인 중국어 음성은 여기서만 나온다
npm test
npm run app:build  # release/ 에 맥 앱 생성
```

낭독은 메인 프로세스에서 합성한다(`electron/ttsBridge.js`). 렌더러는 CSP 때문에
음성 엔드포인트에 직접 붙지 못한다.

## 남는 것

원고·읽던 위치·설정은 브라우저 `localStorage`에만 저장된다. 합성한 오디오는
메모리에만 두고 디스크에 쓰지 않는다. 음성 합성을 위해 문장이 마이크로소프트
서버로 전송되며, 설정에서 오프라인 전용(기기 음성)으로 바꿀 수 있다.
