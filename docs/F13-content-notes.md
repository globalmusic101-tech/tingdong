# F13 학습 자료 작성 원칙

- 중국어 원문·절 번호·단락 경계는 기존 eBible cmn-cu89s 마가복음 1장 자료를 유지합니다.
- 한국어와 영어 뜻은 이 앱의 중국어 학습용 풀이입니다. 특정 성경 번역본을 전재하거나 해당 번역본의 공식 본문으로 표시하지 않습니다.
- 두 언어는 같은 중국어 절의 내용을 풀이합니다. 절 경계에서 문장이 이어지면 그 연결도 유지합니다.
- 단어 뜻은 해당 본문의 문맥으로 좁힙니다. 예: 福音=복음/good news, 教训=가르침/teaching, 试探=시험·유혹/temptation.
- 각 단어·문법 카드는 실제 출처 절과 그 절의 부분 문자열을 함께 갖습니다. 5절씩 모드에서도 같은 출처 절을 기준으로 걸러냅니다.
- 문법 설명은 언어 구조를 설명합니다. 신학적 논점이나 본문에 없는 해석을 정답으로 덧붙이지 않습니다.
- 문법의 현대 연습 예문은 앱이 작성한 예문으로 표시하여 성경 구절과 구분합니다.
- 카드의 기억함/다시 공부는 사용자의 자기 확인 기록입니다. 암기 시험 점수나 자동 SRS 일정으로 표시하지 않습니다.
- 병렬 뜻·학습 설명은 사용자 명시 요청에 따라 한국어와 영어를 함께 표시합니다. 메뉴·상태 문구는 기존 UI 언어 규칙을 유지합니다.
