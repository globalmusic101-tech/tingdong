## 온라인 음성 실측과 수정

기존 `registerTtsBridge`의 실제 합성 핸들러로 공개 성경 문장을 요청했습니다.
결과: `Edge TTS WebSocket error: Unexpected server response: 403`.
패키지 앱에서도 온라인 선택 → 문장 클릭 → 실패 안내 → 기기 음성 재생을 확인했습니다.
온라인 서비스 성공으로 기록하지 않습니다. 처음부터 기기 음성이 기본값입니다.

실패한 온라인 서비스에 반복마다 요청하지 않도록 현재 플레이어는 실패를 기억하고 기기 음성으로 계속 읽습니다.
설정을 바꾸면 재시도할 수 있습니다. 이 동작과 이후 prefetch 억제는 단위 테스트로 확인했습니다.
기기 음성 오류를 onEnded로 처리하던 경로도 분리하여 실패 시 반복이 멈추고 오류를 표시합니다.
