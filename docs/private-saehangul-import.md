# 개인용 새한글성경 로컬 불러오기

띵동 저장소와 배포 앱에는 새한글성경 본문이 포함되지 않습니다. 사용자가 별도로 권리를 확인해 준비한 마가복음 1장 JSON 파일을 앱에서 불러오면 앱 전용 userData/private-bible 폴더에 저장합니다. 본문은 네트워크로 전송하지 않습니다.

필수 형식은 version 1, translation saehangul-2025, book Mark, chapter 1, 그리고 1부터 45까지의 모든 절입니다. 실제 절 본문은 사용자가 별도로 준비해야 하며 저장소에는 예시 본문도 넣지 않습니다.

앱을 공유받은 다른 사용자는 이 파일을 갖고 있지 않으므로 기본 한국어 성경 1910을 사용하고, 자신의 승인된 파일을 직접 불러와야 합니다.
